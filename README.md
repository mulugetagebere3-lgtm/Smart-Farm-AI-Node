# 🌿 Smart Farm AI Node (Raspberry Pi 5)

An intelligent irrigation system that uses Machine Learning to predict soil moisture needs in real-time.

## 🚀 Key Features
- **AI-Powered:** Uses an XGBoost model for precision farming.
- **Edge Computing:** Runs locally on Raspberry Pi 5.
- **Web Interface:** Real-time Flask dashboard with dynamic charts.
- **Automated Monitoring:** Auto-refreshes data every 5 seconds.

## 🛠️ Built With
- **Python** (Flask, Pandas, Joblib)
- **Machine Learning** (XGBoost)
- **Frontend** (HTML, Chart.js)
- **Hardware** (Raspberry Pi 5)

## 📂 How to Run
1. Clone the repo.
2. Run `python3 web_app.py`.
3. Open your browser at `http://<your-pi-ip>:5000`.
